# Лабораторная работа №1: Проектирование и реализация базового класса на C++

### Обзор проекта
Этот проект — фундамент курса ООП. Здесь реализована работа с кастомным типом данных, где основной упор сделан на **инкапсуляцию** и **управление жизненным циклом объекта**. 

> **Почему это важно для ML Platform:** В высоконагруженных системах (например, инференс моделей) критически важно понимать, как объекты создаются и уничтожаются в памяти. Ошибки на этом уровне ведут к утечкам ресурсов, которые недопустимы в продакшене.

## Реализованные концепции

* **Инкапсуляция**: Все внутренние данные класса скрыты (private), доступ осуществляется через контролируемый интерфейс (getters/setters).
* **Жизненный цикл (RAII)**: Реализованы конструкторы (по умолчанию, с параметрами, копирования) и деструктор для безопасной работы с ресурсами.
* **Валидация состояний**: Класс проверяет корректность входных данных, предотвращая переход объекта в невалидное состояние.
* **Разделение интерфейса и реализации**: Код структурирован по файлам `.h` (объявление) и `.cpp` (логика).

## Технологический стек
* **Язык**: C++ (стандарт 11/14/17).
* **Компилятор**: GCC / Clang.
* **Сборка**: Makefile.
