# Объектно-ориентированное программирование на C++ (Лабораторные работы)

### Обзор проекта
В данном репозитории собраны учебные проекты, выполненные в рамках курса «Объектно-ориентированное программирование» (2 курс). Каждая работа направлена на освоение ключевых парадигм проектирования надежных и производительных систем на языке C++.

> **Важно для ML Platform:** Проекты демонстрируют мои навыки управления ресурсами (RAII), проектирования интерфейсов и написания типобезопасного кода. Эти знания необходимы для оптимизации вычислительных ядер ML-библиотек и разработки инфраструктурных сервисов.

## Основные реализованные концепции

* **Управление памятью и ресурсами (RAII)**: Реализация конструкторов, деструкторов и "Правила пяти" для предотвращения утечек памяти.
* **Иерархии классов и Полиморфизм**: Использование виртуальных функций для создания гибких и расширяемых архитектур.
* **Обобщенное программирование (Templates)**: Написание шаблонных классов и методов для работы с различными типами данных без потери производительности.
* **Перегрузка операторов**: Создание интуитивно понятных интерфейсов для пользовательских типов данных.

## Технологический стек
* **Язык**: C++ (стандарты 14/17).
* **Среда**: GCC / Clang.
* **Инструменты**: GNU Make для автоматизации сборки.
